# @courier/nz-address — the NZ address normaliser

**Published 2026-11-08 for the voice handover (founder directive 2026-11-08, item 1).**
This package is the shared, non-voice home of the address normaliser; the lead's
voice slice imports it read-only.

## The two normaliser surfaces

| Surface | Path | Language | Used by |
|---|---|---|---|
| The package (parser, constants, schemas) | `packages/nz-address/src/` — entry `src/index.ts` re-exports `parser.ts`, `constants.ts`, `schemas.ts` | TypeScript/Zod | the app (`apps/mobile`), shared code |
| The API twin | `services/api/app/nz_address.py` (deterministic normaliser, runs before and after the LLM; `services/api/app/address_correction.py` rides it) | Python | `services/api` (the D8 engine, the import endpoint) |

Both implement the same normalisation (the TS was ported from the Python — see the
header of `src/index.ts`), so a sentence means the same address online and offline.

## The LINZ hotword list

`packages/nz-address/data/linz-hotwords.json` — generated by
`scripts/data/export-linz-hotwords.py` from the build-local LINZ index
(`data/linz/addresses-<area>.jsonl`, gitignored per ADR-003). It is a **derived name
list** (unique road/suburb/town names plus macron-stripped spoken forms; no address
numbers, no raw LINZ bulk), carrying the CC BY 4.0 attribution line in its header:

> Sourced from the LINZ Data Service and licensed for reuse under the CC BY 4.0 licence.

Regenerate after a LINZ changeset import:
`uv run python scripts/data/export-linz-hotwords.py --execute`
