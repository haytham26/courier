# مواصفات المنتج — Courier Copilot
### «مساعد يدير يومك كاملًا بالصوت، والهاتف على الستاند»

> هذه الوثيقة هي المرجع قبل البناء. مبنية على: بحث المنافسين (`COMPETITIVE_RESEARCH.md`) + مقابلة السائق (`DRIVER_INTERVIEW_1.md`).
> قاعدة التصميم: **نأخذ من المنافسين ما أثبت نجاحه في الواجهات، ونبتكر في ما لا يفعله أحد: الصوت، الذاكرة، القواعد.**

---

## 1. فلسفة المنتج (3 مبادئ لا نكسرها)

1. **الصوت هو الواجهة، والشاشة تأكيد.** كل شيء يُعمل بالصوت. الشاشة تُظهر ما فهمه المساعد ليراه السائق بنظرة.
2. **المساعد يعرف متى يسكت.** أسوأ مساعد هو الذي يقاطع. في وضع الإملاء يسكت تمامًا. أثناء القيادة يتكلم أقل من 15 كلمة.
3. **التطبيق يصير أذكى كل يوم.** كل عنوان، كل باب، كل قاعدة تُحفظ. اليوم المئة أسرع بكثير من اليوم الأول. **هذا هو الخندق ضد المنافسين.**

## 2. يوم السائق كاملًا مع المساعد

```
 06:30  الاستلام ─────► 07:00 التحميل ─────► 07:15 القيادة والتسليم ─────► 15:30 نهاية اليوم
  إملاء صوتي + مسح      الترتيب حسب خط السير      المساعد يقود كل محطة          ملخص + تعلّم
```

### 2.1 وضع الإملاء الصوتي (Dictation Mode) — ميزة الاستلام الأساسية

**السيناريو:**
> السائق: «يا كوبايلوت، بدي أبدأ أسجّل العناوين»
> المساعد: «جاهز. احكي، وأنا ساكت لحد ما تقول خلصت.» *(نغمة بدء)*
> السائق: «14 Harewood Road… 22B Main North… 7 Sawyers Arms، لا لا 17… 3 slash 9 Grimseys… خلصت»
> المساعد: «سجّلت 4. ثلاثة واضحين. واحد بدي أتأكد منه: Main North Road — رقم 22B، Papanui ولا Northcote؟»
> السائق: «Papanui»
> المساعد: «تمام. 4 عناوين، كلها في خط سير نورثود. أكمل؟»

**كيف يعمل تقنيًا (آلة حالات):**

```
IDLE ──"بدي أسجّل"──► LISTENING (صامت تمامًا، يظهر النص حيًا على الشاشة)
                         │  كل عنوان مكتمل ← بيب خفيف + يظهر كبطاقة خضراء/صفراء/حمراء
                         │  "لا لا 17" ← يصحّح آخر عنوان فورًا (آخر تصحيح يكسب)
                         │  "امسح الأخير" ← يحذفه
                         │  صمت 8 ثوانٍ ← لا شيء (يبقى يسمع؛ لا يقطع)
                         ▼ "خلصت" / "بس" / زر السماعة مرتين
                     REVIEWING  ── الأخضر: يُقبل بصمت
                         │          الأصفر: سؤال واحد قصير لكل عنوان (خيارين فقط)
                         │          الأحمر: "ما فهمت العنوان الثالث، أعده؟"
                         ▼
                     CONFIRMED ── يُدمج في خط السير ← "4 عناوين، أكمل؟"
```

**ألوان الثقة لكل عنوان (تظهر حية أثناء الكلام):**
- 🟢 **أخضر:** موجود في ذاكرة السائق (سلّم له قبل) أو تطابق تام مع سجل العناوين الرسمي LINZ ← يُقبل بلا سؤال.
- 🟡 **أصفر:** الشارع موجود في أكثر من ضاحية، أو الرقم غير موجود في الشارع، أو ثقة سماع منخفضة.
- 🔴 **أحمر:** لا يوجد مثله ← يُعاد السؤال.

**التصحيح الذكي (ما لا يفعله أحد):**
- يعرف **منطقة السائق**: إذا قال «Main North» وهو مقاول Northwood، يختار الأقرب لمنطقته أولًا.
- يتحقق أن **الرقم موجود فعلًا** في الشارع (من LINZ): «Harewood Road رقم 1400 غير موجود، قصدك 140؟».
- يفهم **طريقة كلام السائق**: الأرقام المتقطعة، الأسماء الماورية، «slash»، «B».
- **الدمج مع المسح:** يقدر يمسح الملصق بالكاميرا ويكمّل بالصوت ما لم يُقرأ («هذا 14 ونص الملصق ممسوح، الشارع Harewood»).

### 2.2 وضع القيادة — الهاتف على الستاند

**الشاشة:** خريطة + بطاقة المحطة الحالية. **السائق لا يلمس شيئًا.**

| السائق يقول | المساعد يفعل |
|---|---|
| «يلا نبدأ» | يحمّل خط السير اليومي، يقول المحطة الأولى، يفتح الملاحة |
| *(يقترب 150م)* | يهمس: «بعد 150 متر يمين. البوابة الجانبية يسار الكراج.» |
| *(يقترب 30م)* | «أوقف هنا. الطرد في الرف الوسط، صندوق صغير.» |
| «تم» / «تركته عند الباب» | يسجّل التسليم + الموقع + يقول المحطة التالية |
| «ما حدا بالبيت» | يسأل: «أتركه بمكان آمن ولا أرجعه؟» |
| «الدبوس غلط، البيت هنا» | يحفظ الموقع الحالي كنقطة الباب للأبد |
| «ارجع له بعدين» | ينقله لآخر الشارع أو آخر اليوم |
| «في زحمة، شو أعمل؟» | يقترح تبديل ترتيب الشوارع القادمة **ضمن قواعد السائق** |
| «كم باقي؟» | «63 محطة، تقريبًا ساعتين و10 دقائق» |
| «سجّل: في كلب» | ملاحظة دائمة على العنوان |
| «استراحة» | يوقف كل شيء، يتذكّر أين وصل |

### 2.3 إدارة خطوط السير والقواعد بالكلام

> «اعمل خط سير اسمه هورنبي الخميس، ابدأ من Main South Road بعدين Carmen Road»
> «شو قواعدي؟» ← يقرأها
> «احذف قاعدة المدرسة»

**القاعدة = بيانات منظّمة، ليست نصًا** — المساعد يحوّل الكلام إلى:
```json
{"type":"order_before","a":"street:northwood:*","b":"street:redwood:*"}
{"type":"avoid_window","street":"Harewood Rd","from":"15:00","to":"15:45"}
{"type":"side_order","street":"Main North Rd","mode":"odd_first"}
{"type":"load_last","size":["large","heavy"]}
{"type":"safe_place","address":"14 Harewood Rd","place":"back door"}
```
ثم يقرأها للسائق ليؤكد. **الخوارزمية تطبّق القواعد، والمساعد يشرحها فقط** — لا هلوسة في الترتيب.

## 4. الواجهات — مستوحاة من المنافسين، مُحسّنة للصوت

**الأسلوب البصري:** نظيف، تطبيق أصلي (Native) مثل Spoke وApple Maps — **ليس** شكل «تطبيق ذكاء اصطناعي» (لا فقاعات شات، لا تدرّجات بنفسجية، لا روبوت). المساعد يظهر فقط كـ**شريط صغير نابض** أسفل الشاشة.

| العنصر | مأخوذ من | تحسيننا |
|---|---|---|
| خريطة أعلى + قائمة محطات في Bottom Sheet قابل للسحب | Spoke / Circuit | نفس النمط تمامًا (مألوف للسائقين) |
| بطاقة المحطة الحالية بأزرار كبيرة | Spoke | الأزرار احتياط؛ شريط «يسمع» يوضح الأمر الصوتي المفهوم |
| رقم الطرد في الشاحنة (Package Finder) | Spoke | يُقال بالصوت + منطقة ملونة |
| المسح بالكاميرا | Zeo / Routal | مسح متواصل بدون ضغط + مطابقة فورية مع الذاكرة |
| الملاحة الداخلية + التحويل لتطبيق خارجي | Upper / Spoke | التحويل بالإحداثية المحفوظة |
| تصميم البطاقات والقوائم | Apple Maps / Uber Driver | وضع داكن تلقائي، خط عملاق في القيادة |

### الشاشات
1. **الرئيسية (اليوم):** «خط سير نورثود الصباح · 214 طرد · 0 مسح» + زرّان ضخمان: 🎙 **إملاء** · 📷 **مسح**. أسفلها قائمة خطوط السير المحفوظة.
2. **الإملاء:** نص حي يكتب نفسه، بطاقات العناوين تظهر وتتلوّن (🟢🟡🔴)، عدّاد كبير، موجة صوت. لا أزرار تقريبًا.
3. **المراجعة:** فقط العناوين الصفراء والحمراء، كل واحدة بخيارين كبيرين (يمكن الرد بالصوت أو اللمس).
4. **المسح:** كاميرا ملء الشاشة، إطار يقرأ تلقائيًا، «بيب» + بطاقة تنزلق لأسفل لكل طرد.
5. **القيادة:** خريطة 70% + بطاقة المحطة: **«14»** بخط 64pt، «Harewood Rd»، أيقونة منطقة الشاحنة، سطر الباب. شريط المساعد النابض.
6. **محرر خط السير:** قائمة الشوارع بالسحب والإفلات + الخريطة ملونة بالترتيب + قائمة القواعد.
7. **بطاقة العنوان:** صورة القمر الصناعي + 3 دبابيس (Google / الوقوف / الباب) + الملاحظات + سجل التسليمات.
8. **نهاية اليوم:** إحصاءات + الأرباح + «تعلّمت اليوم 12 بابًا جديدًا».

## 6. البنية

```
┌─────────────────────────── الهاتف (Expo) ───────────────────────────┐
│ Porcupine (تنبيه) ─► Silero VAD ─► sherpa-onnx (أوامر سريعة offline) │
│                         └──► Deepgram stream (إملاء/كلام حر)         │
│ VisionCamera + ML Kit (مسح)    MapLibre (خريطة)   SQLite (كل البيانات)│
│ محرك الأوامر المحلي: تم/تخطّ/التالي ← يعمل بدون إنترنت                 │
└──────────────── WebSocket + مزامنة أحداث ────────────────────────────┘
                              │
┌────────────── الخادم (FastAPI + LangGraph) ──────────────┐
│ وكيل الإملاء والمراجعة · وكيل القواعد · وكيل الذاكرة المكانية │
│ مُرتّب خط السير (قواعد + Template + VROOM)                  │
│ Postgres/PostGIS/pgvector · LINZ · Valhalla                │
└────────────────────────────────────────────────────────────┘
```
**قاعدة ذهبية:** أي أمر يحتاجه السائق وهو يقود يجب أن يعمل بدون إنترنت وفي أقل من 300ms.

| **5–6** | خطوط السير المحفوظة + القواعد + المسح بالكاميرا | يبني خطوط سيره |

| **9–10** | إصلاح كل ما ظهر + offline كامل + زر السماعة | يستخدمه وحده |

**قياس النجاح للتجربة:**
- الاستلام: من 60–120 دقيقة ← **أقل من 15 دقيقة**.
- الوصول للمكان الغلط: ← **صفر للعناوين المتكررة** بعد أسبوعين.
- لمسات الشاشة أثناء القيادة: ← **أقل من 10 في اليوم**.
- الأوامر الصوتية المفهومة من أول مرة: ← **أكثر من 95%**.

## 8. التوسع العالمي
النظام مصمّم كـ**طبقات بلد**: كل بلد = بيانات عناوين رسمية + قاموس نطق + صيغة عنوان. نيوزيلندا أولًا (سوق صغير لكن مثالي للتجربة)، ثم أستراليا (نفس الشركات والنمط)، ثم بريطانيا وكندا وأمريكا (ملايين سائقي Amazon DSP وFedEx المستقلين). **الذاكرة المكانية تجعل كل بلد ندخله أصعب للمنافسين.**
