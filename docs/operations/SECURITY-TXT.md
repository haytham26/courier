Notes:

  stale silently — the pen-test checklist re-checks it, PARITY 213).
- The PGP key line points at `pgp-key.txt`; publishing the key is part of the same
  edge task (FOUNDER_TODO — the key is generated by the founder, never committed).
- `Canonical` pins the URL so mirrors cannot fork the policy.
