## 4. Innovation Principles (Guardrails)

| Principle | Enforcement |
|-----------|-------------|
| **Offline-First for Driving** | Any driving command must work offline <300ms |
| **AI Never Picks Address** | AI only phrases; selection = LINZ match + driver memory |
| **No Screen Touch While Moving** | Driving screen = voice + earbud buttons only |
| **Driver Data = Driver Owned** | Export anytime. Delete anytime. No selling. |
| **Privacy by Design** | Gate codes encrypted. PII masked in analytics. NZ residency. |
| **Compounding Value** | Every feature must make tomorrow faster than today. |
